# DAChecklive Shop Pro

Bot shop Telegram có:
- Menu user và Admin riêng
- Thêm/sửa/xóa sản phẩm bằng nút
- Quản lý kho bằng cách nhập nhiều item
- Tự động trừ số dư, xuất item trong kho và tạo đơn
- Duyệt/từ chối yêu cầu nạp
- Lịch sử đơn hàng, nạp tiền, thống kê
- Health endpoint cho Render

## Render
Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`

Environment:
BOT_TOKEN, ADMIN_IDS, SHOP_NAME, MIN_DEPOSIT, PORT

Không đưa token thật vào GitHub.
